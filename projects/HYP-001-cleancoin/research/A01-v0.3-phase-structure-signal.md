# A01 v0.3 — Phase-timing model-structure signal

Status: **POSITIVE MODEL-STRUCTURE SIGNAL — NOT MATERIAL FEASIBILITY EVIDENCE**

## Purpose

Test whether one shared reduced-order preparation/use mechanism can generate the large source-observed shift in degradation onset caused by changing only the virtual CaCl₂ crosslinking duration from 1 min to 5 min.

Primary phase targets from Tavakoli et al. (2019), DOI `10.1016/j.msec.2019.109951`:

- 1-min crosslink: swelling ends / degradation begins at approximately 30 min;
- 5-min crosslink: swelling continues to ~240 min, equilibrium ~240–360 min, degradation begins after ~360 min.

## v0.3 mechanism

`cleancoin_lab.phase_model` reuses the v0.2 preparation and 1-min rinse simulation, then during use:

1. temporary junctions dissociate;
2. their cumulative loss generates a reduced `expansion_proxy` relative to the persistent junction scaffold established during preparation;
3. the proxy relaxes toward that fixed-charge/expansion drive;
4. persistent/chelate-junction dissociation is strongly suppressed until the proxy crosses a shared critical threshold.

The expansion proxy is explicitly **not** a physical strain variable. It is a placeholder for missing swelling/poroelastic mechanics.

## Exploratory reference point

Using the current exploratory defaults (not calibrated):

- virtual 1-min preparation → degradation activation ~**36 min**;
- virtual 5-min preparation → degradation activation ~**369 min**.

This comparison uses the same use-stage laws for both samples. Only preparation duration changes the generated initial network state.

The numerical closeness to the source timings should not be interpreted as independent prediction: the reduced structure and exploratory defaults were informed by the source phase behavior. The relevant result is that the mechanism can express the observed preparation-history effect without an explicit `crosslink_duration_factor` or separate per-sample use-stage decay constants.

## Local robustness screen

A deterministic exploratory screen perturbed the eight reduced parameters around the reference point by multiplicative factors spanning approximately ±20% (120 samples; coarse numerical resolution used only for research-order assessment).

Observed onset distribution:

### 1-min preparation

Central 90% of onset times: approximately **29–48 min**.

### 5-min preparation

Among finite onsets inside the 8-h simulation horizon, central 90%: approximately **187–429 min**. Some perturbations did not activate degradation within 8 h.

### Joint coarse criteria

- about **65%** of perturbations produced a 1-min onset in 20–60 min and a 5-min onset later than 300 min;
- about **49%** produced a 1-min onset in 20–60 min and a 5-min onset later than 360 min.

These percentages are not statistical confidence or posterior probability; the perturbation distribution itself is arbitrary. They only show that the qualitative phase-separation behavior occupies a neighborhood rather than one isolated numerical point.

## What this does establish

The combination

`preparation history -> persistent/temporary network state -> delayed expansion state -> thresholded chelate failure`

is a viable reduced model architecture worth calibrating against primary data.

## What this does NOT establish

It does not establish that:

- the real material will meet CleanCoin's 10–30 min target;
- the exploratory binding, maturation, dissociation, expansion or threshold parameters are physically correct;
- the expansion proxy is a valid constitutive law;
- a cellulose/CNF-reinforced version will share the bead kinetics;
- a dry compressed porous geometry will reproduce the wet-bead mechanism.

## Highest-value next evidence

The model is now most sensitive epistemically to the mapping between temporary-junction loss and actual swelling/strain. The next evidence search should therefore prioritize time-resolved primary measurements that jointly report one or more of:

1. calcium release or ion-exchange;
2. bead/gel volume or swelling ratio;
3. modulus or mechanical state;
4. gel-front / crosslink-state evolution;
5. preparation duration.

The purpose is to replace `expansion_proxy` and its threshold with a source-calibrated swelling/mechanics state before moving to HYP-001's wet mechanical-survival gate.
