This note records a local ±20% sensitivity analysis of the **uncalibrated** `cleancoin_lab.ca_model`. It is used only to decide which missing parameters deserve research effort first. It is not evidence that A01 meets HYP-001.

## Research consequence

The next calibration effort should prioritize, in order:

1. initial/accessible temporary-junction Ca²⁺ inventory or a defensible normalization of it;
2. temporary-junction dissociation kinetics;
3. mobile Ca²⁺ transport / effective diffusivity in the hydrated network;
4. characteristic geometry / diffusion length;
5. water transport.

Strong-junction kinetics should be constrained after the early/swelling regime is calibrated or when data enter the collapse regime.

## Numerical checks

The v0.1 implementation passed 7/7 local tests after addition, including:

- nonnegative monotonic external Ca²⁺ release;
- non-growing bound-junction fraction;
- calcium mass balance to numerical precision;
- faster hydration for a thinner slab when the explicit solver is run at a stable timestep.

## Warning

Sensitivity rankings are themselves local to model structure and the exploratory reference point. A parameter can appear low-sensitivity merely because the simulation has not yet reached the regime where it becomes active. This is exactly the case for the strong-junction parameters at 30 min in the current reference run.
