# Decision log

## D-001 — Lab before platform/game

Build CleanCoin as a real Hypothesister research project before generalizing the platform or implementing the game. Reusable infrastructure is extracted only after recurrence across different projects.

## D-002 — Virtual-first

Use literature, multiscale simulation, uncertainty quantification and active learning to eliminate candidates. Minimize physical experiments to high-information calibration/validation queries.

## D-003 — Bio-derived prior

Prefer predominantly bio-derived, biodegradable/non-persistent material families, while allowing benign inorganic ions/minerals when functionally justified.

## D-004 — Evidence discipline

Simulation output derived from assumed parameters is not evidence of material feasibility. Parameters must preserve provenance and epistemic status.
